Base Matemática — MetSim Studio v2.0

1. Balance de Población (PBM) — Austin Model

El molino resuelve 20 clases de partículas simultáneamente. La ODE de rotura por clase es:

dm_i/dt = −S_i · m_i + Σⱼ₌₁ⁱ⁻¹ B_ij · S_j · m_j

Selección: S_i = α · (d_i / d_ref)^μ · f(P/P_max)

Distribución: B_ij = φ·(d_i/d_j)^γ + (1−φ)·(d_i/d_j)^β

2. Ciclón — Curva de Tromp Real por Clase

Cada clase de partícula tiene su propia fracción al underflow según la curva de Tromp:

Y_i = Ra + (1−Ra) / (1 + (d₅₀c/dᵢ)^α)

Donde Ra = bypass/100, α = 1/imperfección. Agua al U/F: Rf ≈ bypass/100 · 1.2.

3. Control PID del Sump (con Anti-Windup)

v(t) = Kp·e(t) + Ki·∫e(t)dt + Kd·(de/dt) + v₀
integral = clamp(integral, −60, +60) ← anti-windup

Elimina el offset estacionario (componente integral) y anticipa oscilaciones (derivativa).

4. Balance de Agua y Densidad de Pulpa

ρ_pulpa = (Qsólidos + Qagua) / (Qsólidos/ρ_mineral + Qagua)
%w/w = Qsólidos / (Qsólidos + Qagua) × 100

Calculado para cada corriente: alimentación, descarga molino, sump, overflow, underflow.

Residual global: Δsól = Feed − Overflow ≈ 0
